# Customer data lifecycle

Paths below identify implemented operations, not proof that a deployment has enabled them or that an external provider has erased data. `none today` means this repository supplies no export or deletion operation for that store. Read endpoints described as partial exports do not constitute a complete customer archive.

The offboarding route in `platform/api.py::offboard` returns 503 when `PLATFORM_ADMIN_TOKEN` is unset. Its `key_purge_hook` and `blob_purge_hook` default to no-ops. An offboarding timestamp or hook invocation is therefore not proof of secret or blob erasure. This matrix does not assert the current token configuration or hook wiring of any live deployment.

The external Stripe and Auth0 rows are bounded to this repository's integration code: `platform/billing.py`, the billing routes in `platform/api.py`, and `server/auth0-actions/post-login-add-tenant-claim.js`. They do not assert provider retention settings or lifecycle operations in the separate website repository. The telemetry expiration above records the existing storage contract, not a new retention policy.
